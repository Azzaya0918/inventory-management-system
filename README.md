# Дэлгүүрийн бараа материал бүртгэх систем

Энэ бол Программ хангамж хөгжүүлэлтийн процесс хичээлийн багийн төсөл юм.

## Багийн гишүүд
- (Э. Мөнх-Очир) (Product Owner)
- (Б. Аззаяа ) (Scrum Master)
- (Э. Тайванбаяр) (Хөгжүүлэгч)

## Төслийн зорилго
Энэхүү төслөөр бид Scrum аргачлалыг дагаж, дэлгүүрийн бараа материалын бүртгэл болон борлуулалтын процессыг автоматжуулсан, бодит цагийн хяналттай веб системийг хөгжүүлнэ. Төслийн хүрээнд хэрэглэгчийн судалгаа дээр үндэслэн багийн гишүүд үүрэг ролийг сэлгэн ажиллаж, системд аюулгүй байдлын шийдэл, тестчлэлийг иж бүрэн хийж, ажиллах туршилтын загварыг (MVP) гаргахад оршино.

## Гол боломжууд (төлөвлөсөн)
- Бараа нэмэх, засах, устгах, хайх
- Барааны орлого, зарлагын бүртгэл
- Үлдэгдэл хянах, үлдэгдэл багасахад сануулах
- Тайлан гаргах

## Хөгжүүлэлтийн арга
Scrum (Sprint, Daily Scrum, Sprint Review, Retrospective)
